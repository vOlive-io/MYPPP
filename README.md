# MYP Personal Project 🎓
This repository contains the code for my MYP Personal Project. My goal was to create a full-stack project and deploy it as an app that can be opened on mobile devices.
## GitHub Pages 🌐
While this will become a mobile app, the GitHub Pages site is open, allowing you to access my work from the web. *This game is intended for use on a mobile device with a smaller screen; larger screens (tablets, computers, monitors) might stretch, distort, or completely inhibit asset viewing and UI navigability.*
## Feature Updates 🚨
This game is based on a previous version of [DungeonDwellers](https://github.com/vOlive-io/DungeonDwellers) a large CYOA-style game I started in 8th grade; however, I never finished it, and it sat in my GitHub repository list collecting dust. This seedling of a game that I started a while ago has been trying to escape and has finally manifested itself into this project. While playing, you will notice many similarities in the game mechanics and playstyles, just simplified to a mobile format.
